# Exercício 10: Lista de Compras

Este é um pequeno programa em JavaScript desenvolvido para praticar a manipulação de arrays (vetores) e estruturas de repetição utilizando o laço `for`.

## 📝 Descrição do Desafio

O objetivo é criar uma lista de compras pré-definida e exibir todos os seus itens formatados na tela, numerados a partir do 1.

### Saída Esperada:
```text
Lista de compras:
1 - arroz
2 - feijão
3 - macarrão
4 - leite
5 - café
